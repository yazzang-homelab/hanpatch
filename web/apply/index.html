한글패치 적용 도구

원본 ROM 을 아래에 끌어다 놓으면 이 브라우저 안에서 패치가 적용됩니다. 파일은 어디로도 올라가지 않습니다 — 서버로 보내는 코드가 아예 없고, 계산은 전부 당신의 CPU 에서, 임시 파일은 당신의 디스크에서만 움직입니다. 결과는 제작자가 빌드한 것과 바이트 단위로 같아야 하며, 도구가 그 해시를 직접 확인해 줍니다.

1. 원본 ROM

여기에 .3ds 또는 .cia 파일을 놓으세요

또는

2. 키 파일

암호화된 카트리지 덤프를 복호화하려면 콘솔 키가 필요합니다. boot9.bin 또는 aes_keys.txt 를 놓으세요. 이 파일도 올라가지 않습니다. 이미 복호화된 덤프라면 건너뛰어도 됩니다.

3. 패치 번들

채널을 읽는 중…

직접 받은 .hpk 가 있으면 여기에 놓으세요 ()

4. 적용

위의 1·3 이 채워지면 시작할 수 있습니다.

기록






  
패치할 게임을 정당하게 소유할 책임과 거주지 법을 지킬 책임은
  이용자에게 있습니다. 이 도구는 번역문과 글꼴만 다루며 게임 데이터를 배포하지
  않습니다. 같은 일을 명령줄에서 하려면
  pip install hanpatch 뒤 hanpatch apply,
  갱신 확인은 업데이트 채널을 보세요.
